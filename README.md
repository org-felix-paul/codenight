# Codenight

The Codenight is a day of coding in schools. 
It is designed to make fun and get students curious about computer science by creating their own peace of working software like an animal website, a car game, table tennis game or a tic toc ai.

This page is built with mdbook.
It could be that you have to run ~/.cargo/bin/mdbook instead of just mdbook if it has not been added to path yet.
